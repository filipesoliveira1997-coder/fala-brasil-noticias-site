# Fala Brasil Notícias

Site estático responsivo para GitHub Pages.

## Publicação
1. Faça upload dos arquivos e pastas deste pacote para a raiz do repositório `fala-brasil-noticias-site`.
2. Preserve o arquivo `tiktokYoT7iEEqWpSpFZTWs3ezt9vbCqPeCoTF.txt` na raiz.
3. No GitHub, confirme em Settings → Pages que a publicação usa a branch principal e a pasta `/ (root)`.
4. Aguarde a publicação e teste a página inicial, matérias, editorias, privacidade e termos.

O portal é estático: as matérias de demonstração são conteúdos editoriais informativos incluídos no pacote. Para operar como veículo de notícias atualizado, a redação deve revisar e publicar novos conteúdos regularmente.
